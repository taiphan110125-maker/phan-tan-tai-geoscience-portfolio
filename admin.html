SECURITY

Bảo mật

Trạng thái hệ thống

  • Admin authenticationKhu quản trị bắt buộc đăng nhập bằng Supabase Auth và kiểm tra vai trò admin bằng Row Level Security.
  • Không lưu API key trong frontendThiết kế giữ khóa bí mật ra khỏi mã nguồn public.
  • Escape nội dung hiển thịGiảm rủi ro chèn HTML từ dữ liệu người dùng khi hiển thị trong khu quản trị.

Production checklist

  • Supabase Auth + quản lý tài khoản người dùng
  • Row Level Security cho database và Storage
  • 2FA cho tài khoản chủ website
  • Rate limit + CAPTCHA cho form public
  • Audit log + backup + rollback
